# XXD Panel 095 · 日本語読解訳

アップロードされた各写真を、それぞれ独立した上質なデザインポスターにします。複数写真を組み合わせず、一枚ずつ出力します。全体は3:4縦位置で、上下二領域の高さを厳密に1:1、各50%にします。

上半分には元写真を残し、主体の同一性、構造、姿勢、実在感、自然な光と影、元の色彩の雰囲気を保持します。アート誌、独立出版物、展覧会写真の質感になる程度の控えめな上質調整だけを施します。必要なら周囲を自然に拡張しても構いませんが、主体の引き伸ばし、歪み、改変は禁止です。

下半分では、最も識別性の高い**主体、輪郭、構造、姿勢、物語関係**を抽出し、**Mid-century modern diagrammatic editorial illustration**として再構成します。写実描写を避け、**visual shorthand / pictographic simplification**により、同一性を決める外輪郭、構造節点、方向、動作、象徴関係だけへ圧縮します。細線、単純幾何、弧線、アイコン、部分断面、技術図記号で表現し直し、一目で元を認識できる図解にします。

構成は硬直した格子ではない**モジュール型インフォグラフィックの論理**です。明確な主図解を一つ視覚アンカーとして置き、必要最小限の局部特徴、動作、環境関係、象徴だけを小さな補助図へ変換します。尺度差、ずれ、整列、引出線、大きな余白で読解経路を作ります。空間は平面的に保ち、技術マニュアル、放送資料、交通図解、古い雑誌図版のように分解・並置・接続しても、中心は一つにし情報を詰め込みません。

主要言語は、簡潔、均一、抑制的な**黒または濃墨の細線**です。手描き技術図と初期印刷図版の質感を持たせ、建築は重要な輪郭と構造、人物や動物は姿勢と動作、植物は成長形態、器物は構造的特徴、景観は地形線、水平関係、経路、波紋、方向などへ圧縮します。対象を美しく描くのでなく、明快に説明します。

配色は暖白またはわずかに灰黄の紙を使う古典的な**黒赤二色の特色印刷**です。黒がほぼ全ての輪郭、構造、情報を担い、朱赤、珊瑚赤、印刷赤は重要構造、動作節点、語、経路、信号、領域、象徴だけに**特色**として正確に置きます。黒・赤・紙白の面積関係でリズムを作り、軽いインク粒子、紙繊維、版ずれ、オーバープリントを残します。グラデーション、多色、汚い経年加工、偽古フィルターは避けます。

文字は見出し欄ではなく図解システムの一部です。写真のテーマ、場所、動作、状態、音、暗示からごく少量の意味ある言葉を生成し、言語や情報種別を固定しません。**小さく明瞭で、活版のわずかなずれを持つモダニズム系細身サンセリフ**を使い、アイコン、引出線、赤印、余白、番号関係へ統合して技術出版物の編集注記にします。

完成像は、**大きな余白、黒い技術線描、赤の特色強調、絵記号的抽象、モジュール図解、旧式印刷の肌理**による上質な編集ビジュアルです。理性的、明晰、知的、抑制的でありながら人間味を保ち、ミッドセンチュリー、初期情報デザイン、独立系アート出版の気質を備えます。写実挿絵、幾何色面の都市画、複雑な透視、漫画アイコン、多色情報図、Tech UI、装飾過多、定型復古ポスターは避けます。
